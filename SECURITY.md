# jEAP OSS Security Policy

All jEAP Open Source repositories follow the security issue reporting process outlined in
[jeap-admin-ch/SECURITY.md](https://github.com/jeap-admin-ch/jeap/blob/main/SECURITY.md).

To report a security issue, use the GitHub Security Advisory
[Report a Vulnerability](https://github.com/jeap-admin-ch/jeap-spring-modulith-error-handling-starter/security/advisories/new)
feature. Do not publicly disclose vulnerabilities before the maintainers have investigated them.
